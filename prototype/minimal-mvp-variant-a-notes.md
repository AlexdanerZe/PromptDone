# PromptDone A 方案：独立数据资产与工作流引用

- **依据：** 用户明确选择原 A「资产导航」方案，要求数据与工作流相互独立，同一份数据可以用于两个工作流，本轮只调整 A。
- **原型：** [单文件 A 原型](minimal-mvp-variant-a-prototype.html)，双击即可运行。预览默认打开数据页，便于直接检查共享关系。
- **记录：** [页面结构决策](https://github.com/AlexdanerZe/PromptDone/issues/66)、[完整文档审阅](https://github.com/AlexdanerZe/PromptDone/issues/67)。
- **边界：** 全部为虚构样本、固定响应与内存状态；刷新重置，没有上传真实文件、调用模型或持久化数据库。历史 A/B/C 和上一轮原型保留为讨论档案，本次不修改 B/C。

## 一、背景与本轮结论

上一轮把任务目录保留在数据区，使数据操作仍围绕当前任务展开。用户本次选定 A：数据是工作区独立资产，工作流通过明确版本引用复用它。两者不互相要求先创建对方。

## 二、价值与可检查示例

- “商品原始导出 v1”同时被“商品字段清洗与分类”和“商品英文卖点生成”引用；使用同一版本与记录标识，不为工作流复制数据。
- 工作流保存自己的 Prompt、节点、模型、运行和标注。共享输入不共享可变调优状态。
- “出海短文案样本”尚无引用，仍是可浏览的独立数据资产。
- 发布新版本后，工作流继续引用原版；只有明确选择目标和版本才改变后续跑测。

## 三、页面、交互与数据处理

### 左侧一级资产导航

**内容说明：** 保留 A 的数据集、工作台、版本对比独立入口，模型与访问从配置进入。不再提供 A/B/C 切换器。

**交互样式：** 切换数据页只显示独立资产；进入工作台后，任务目录与详情在同一页面，历史在任务内展示，不另拆任务列表页。对比明确所选工作流。

**input：** 工作区数据目录、工作流目录及当前导航状态。

**process：** 数据预览与工作流编辑分别保存上下文，导航本身不更改引用或取消运行。

**output：** 独立数据页或包含工作流目录与调优主体的工作台。

### 数据页：目录、版本与引用工作流

**内容说明：** 数据列表展示名称、版本数量、最新记录数、引用工作流名称及其版本；支持搜索、新建数据集和新增版本。下方只读预览所选版本，旁边展示引用关系。无引用显示未被引用。

**交互样式：** “在工作流中使用”先显示数据版本，再要求选择目标工作流；默认不选目标，不能隐式修改最近编辑的任务。显示目标原引用与新引用，确认后只更改该工作流后续运行。引用工作流名称可进入其编辑区。

**input：** Dataset、Dataset Versions、Records、工作区 Workflows 及显式选中的目标。

**process：** 多个工作流引用同一不可变版本；列表计数按当前配置，历史使用不混入当前引用数。导入与发布不自动创建/绑定工作流。

**output：** 独立数据资产、版本预览、引用摘要或明确目标的引用更新；其他工作流和历史保持原引用。

### 工作台：独立创建、引用数据与调优

**内容说明：** 工作流目录常驻工作台内；当前工作流展示步骤、运行历史及数据引用卡片。数据卡片包含名称/版本/记录数、同版本引用数及选择/查看入口。步骤可在末尾添加，旧批次保留原步骤快照。

**交互样式：** 新建工作流初始无数据引用，可编辑 Prompt，未选择数据时禁止运行。选择已有数据版本建立引用；换引用只影响当前工作流后续运行。切换工作流保留独立草稿和历史。

**input：** Workflow、Nodes/Prompt Drafts、独立数据版本、Runs 与标注。

**process：** 按 workflow_id 隔离编辑与历史；Run 冻结实际 dataset_version_id 和配置，不因数据发布、引用变化或追加步骤改写。

**output：** 工作流配置、新的运行快照与自身历史。规则/人工评价、翻译、上游复用、报告及 Context Bundle 沿用已确认边界。
